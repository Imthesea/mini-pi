## 核心规则

**1. 最大程度抄原 pi 项目。** 直接复制 Pi 文件的代码，只删掉 V1 不需要的部分（如 fork、branch、extensions、TUI 等）。

**2. 不允许有任何自己的想法。** 包括但不限于：
- 不允许优化代码
- 不允许简化实现
- 不允许重构架构
- 不允许改变命名
- 不允许改变函数签名
- 不允许改变调用关系  
- 不允许合并或拆分文件
- 不允许添加 Pi 里没有的东西

**3. 改动只能是删除 V1 不需要的部分。** 如果删除某段代码后导致无法编译或运行，必须：
- 告知我具体哪里不兼容
- 说明为什么必须改
- 等我同意后再改

**4. 未经我同意，不允许做任何兼容性改动。**

**Why:** 我的能力不够做优化判断，Pi 是唯一正确标准。任何偏离都会导致架构方向跑偏。

**How to apply:**
1. 打开 Pi 对应文件
2. 复制整个文件内容
3. 删除 V1 不需要的部分（fork、branch、extensions、TUI、OAuth 等）
4. 如果删除后编译/运行有问题 → 告诉我哪里不兼容 → 等我同意 → 再改
5. 绝不主动做任何优化、简化、重构
