**目标:** 从零搭建 `@mimi/coding-agent` 包——**极简版 CLI 入口**,提供 `mimi` 命令(单次 + REPL 模式),复用 `@mimi/agent` 的 `AgentHarness`。**0 依赖目标**(除 `chalk` 可选),代码量 ~300-500 行。

**架构:** 薄包装层,把 stdin/argv → `AgentHarness.prompt()` → stdout/事件渲染,加 session 路径决策和 3 个工具绑定。**所有 agent 行为委托给 `@mimi/agent`,本包不重复造轮子**。

**技术栈:** TypeScript 5.9+ / Node.js 22+ / pnpm / vitest / tsx / Node.js 内置 `readline/promises` / `fs/promises`

## 全局约束

- TypeScript 5.9+,`erasableSyntaxOnly`,ES2022 target,Node16 模块
- **所有注释、文档使用中文**
- vitest 用于单元测试,`examples/*.sh` 用于真实跑通
- 每个 Task 完成后必须:vitest 通过 + 对应 example 可用 `bash` 跑通
- 0 依赖:readline/fs/path/child_process 全部 Node 内置,颜色用原生 ANSI(若引 chalk,只在 Task 1 决定)
- 严格 TDD:测试先写
- 范围严格遵守 spec 概述里的"暂不做"清单(TUI、扩展、OAuth、MCP、slash 命令 等全不做)

## Task 2: 事件渲染(display.ts)

**目标**: 实现 AgentHarness 事件到 stdout 的映射,纯文本 + ANSI 颜色。

**关键 API**:
```ts
export interface DisplayOptions {
  stdout: NodeJS.WritableStream;
  isTty: boolean;  // 控制颜色开关
}

export function createDisplay(options: DisplayOptions): {
  formatEvent(event: AgentHarnessEvent): void;  // 单事件 → stdout
  close(): void;                                 // 终止(关闭可能打开的流)
};
```

**事件映射**(从 spec § 4.1):
| 事件 | 输出 |
|------|------|
| `text_delta` | 追加到当前行(无换行) |
| `text_end` | 换行 |
| `thinking_delta` | 灰色追加,前缀 `🤔 ` |
| `thinking_end` | 换行 + 关闭灰色 |
| `toolcall_start` | 蓝色 `🔧 调用工具: <name>(` |
| `toolcall_delta` | 追加 JSON 片段(只缓冲,不输出) |
| `toolcall_end` | 蓝色 `)` + 换行 |
| `tool_execution_start` | 黄色 `▶ 执行中...` + 换行 |
| `tool_execution_end` | 绿/红 + 耗时 + 换行 |
| `turn_end` | 空行(分隔) |
| `error` | 红色 `Error: <msg>` + 换行 |

**ANSI 颜色方案**:
- `\x1b[36m` 蓝 / `\x1b[33m` 黄 / `\x1b[32m` 绿 / `\x1b[31m` 红 / `\x1b[90m` 灰 / `\x1b[0m` 重置

## Task 3: Session 路径决策(session-init.ts)

**目标**: 实现 session 文件路径的生成与解析,集成 `@mimi/agent` 的 `JsonlSessionStorage`。

**产出文件**:
- `packages/coding-agent/src/session-init.ts`
- `packages/coding-agent/__tests__/session-init.test.ts`

**关键 API**:
```ts
export interface InitSessionOptions {
  cwd: string;
  env: NodeJS.ProcessEnv;
  resume?: string;     // --resume <id>
  forceNew?: boolean;  // --new
  sessionDir?: string; // MIMI_SESSION_DIR,默认 <cwd>/.mimi/sessions
}

export interface InitSessionResult {
  storage: JsonlSessionStorage;
  session: Session;
  isNew: boolean;
  sessionId: string;
}

export async function initSession(options: InitSessionOptions): Promise<InitSessionResult>;
```

**逻辑**:
- `resume`: 路径 = `sessionDir + resume + ".jsonl"`;若不存在 → 报错退出
- `forceNew`: 生成新 id(`new Date().toISOString().replace(/[:.]/g, "-")`)
- 默认(无 flag): 找 `sessionDir/*.jsonl` 中 mtime 最新的(24h 内);若找到 → 续接;否则 → 新建

**测试用例**:
- ✅ `forceNew` 总是创建新 session
- ✅ `resume` 存在 → open
- ✅ `resume` 不存在 → 抛错(含 sessionDir 路径)
- ✅ 默认模式:空目录 → 新建
- ✅ 默认模式:有 24h 内 session → 续接
- ✅ 默认模式:有但 24h 外 → 新建
- ✅ sessionDir 不存在时自动创建

## Task 4: 三个工具(tools/)

**目标**: 实现 read_file / write_file / bash 三个工具,绑定到 harness。**所有工具强制 cwd 安全**。

**产出文件**:
- `packages/coding-agent/src/tools/read-file.ts`
- `packages/coding-agent/src/tools/write-file.ts`
- `packages/coding-agent/src/tools/bash.ts`
- `packages/coding-agent/src/tools/index.ts`(导出三个工具 + `BUILTIN_TOOLS` 数组)
- `packages/coding-agent/__tests__/tools/read-file.test.ts`
- `packages/coding-agent/__tests__/tools/write-file.test.ts`
- `packages/coding-agent/__tests__/tools/bash.test.ts`

**read_file**:
- 输入:`{ path: string }`
- 实现:`fs/promises.readFile(cwd-relative path)`
- 安全:`path.resolve(cwd, input)` 必须以 `cwd` 开头(否则返回 `Result.error`)
- 错误:用 `Result<T, ToolError>`,不抛

**write_file**:
- 输入:`{ path: string, content: string }`
- 实现:`fs/promises.writeFile(cwd-relative path, content)`,自动创建父目录
- 安全:同 read_file

**bash**:
- 输入:`{ command: string, timeoutMs?: number, maxOutputBytes?: number }`
- 实现:`child_process.exec(command, { cwd, timeout, maxBuffer })`
- 输出截断:超过 `maxOutputBytes`(默认 50KB)时截断 + 提示
- 超时:默认 30s
- 返回:`{ stdout, stderr, exitCode, durationMs, truncated }`

**类型**:`AgentTool<TParams, TResult>`(用 AI 层定义的接口)
- `parameters` 用 TypeBox schema
- `execute` 返回 `Result<T, ToolError>`(用 `@mimi/agent` 的 `AgentToolResult` 类型)

**测试用例**:
- `read-file.test.ts`:
  - ✅ 读 cwd 下的文件成功
  - ✅ 路径越界(绝对路径 `/etc/hostname`)返回错误
  - ✅ 路径越界(`../../etc/passwd`)返回错误
  - ✅ symlink 逃逸检测(用 `fs.realpath`)
  - ✅ 文件不存在返回 not_found
- `write-file.test.ts`:
  - ✅ 写 cwd 下的文件成功
  - ✅ 路径越界返回错误
  - ✅ 自动创建父目录
- `bash.test.ts`:
  - ✅ 简单命令(`ls`、`echo`)
  - ✅ cwd 生效
  - ✅ 超时返回 timeout 错误
  - ✅ 输出截断(输出 > 50KB)
  - ✅ 非零 exit code 返回错误详情
  - ✅ 路径越界命令(`cd / && ls`)只限制 cwd,不阻止所有绝对路径(因为 bash 内可能合法)

## Task 5: Single-shot 模式

**目标**: 实现 `mimi "prompt"` 的单次执行模式。

**产出文件**:
- `packages/coding-agent/src/single-shot.ts`
- `packages/coding-agent/__tests__/single-shot.test.ts`
- `packages/coding-agent/examples/01-single-shot.sh`

**关键 API**:
```ts
export interface SingleShotOptions {
  prompt: string;
  model?: string;
  thinking?: ThinkingLevel;
  cwd: string;
  env: NodeJS.ProcessEnv;
  display: Display;
  signal?: AbortSignal;
}

export async function runSingleShot(options: SingleShotOptions): Promise<number>;
```

**流程**:
1. 加载 `.env`(若 cwd 下有)
2. `initSession({ cwd, env, forceNew: true })` → 拿到 session
3. 构造 `AgentHarness`:
   - `model`: `options.model ?? env.MIMI_MODEL ?? defaultModel`
   - `thinkingLevel`: `options.thinking ?? env.MIMI_THINKING ?? "medium"`
   - `session`, `env: new NodeExecutionEnv({ cwd })`, `tools: BUILTIN_TOOLS`, `systemPrompt`
4. 订阅 `harness.subscribe()`,每个事件调 `display.formatEvent(event)`
5. `await harness.prompt(prompt)`
6. `harness.close()` + `storage.close()`
7. 返回 0

**错误路径**:
- 缺 API key → 写 `Error: MIMI_API_KEY_ANTHROPIC not set. See .env.example.` 到 stderr → 返回 1
- 模型未知 → 写可用模型列表 → 返回 2
- 其它异常 → `console.error(err)` → 返回 1
- SIGINT(`signal.aborted`)→ `harness.abort()` → 返回 130

**测试用例**:
- ✅ 缺 API key → 返回 1,stderr 有友好提示
- ✅ 缺 API key 但 env 有 → 继续
- ✅ 未知 model → 返回 2,stderr 有可用列表
- ✅ harness 异常 → 返回 1
- ✅ (mock harness) prompt 正常完成 → 返回 0

**example**(`01-single-shot.sh`):
```bash
#!/usr/bin/env bash
set -e
cd "$(dirname "$0")/.."
MIMI_MODEL=claude-sonnet-4-20250514 \
  npx tsx src/cli.ts "今天北京天气怎么样?只回答:晴 / 多云 / 雨 / 雪,选一个"
```

**验证**:
```bash

bash examples/01-single-shot.sh
# 预期: 看到模型响应,退出码 0
```

## Task 6: REPL 模式

**目标**: 实现无参数 `mimi` 的交互式循环。

**产出文件**:
- `packages/coding-agent/src/repl.ts`
- `packages/coding-agent/__tests__/repl.test.ts`
- `packages/coding-agent/examples/02-repl.sh`

**关键 API**:
```ts
export interface ReplOptions {
  cwd: string;
  env: NodeJS.ProcessEnv;
  stdin: NodeJS.ReadableStream;
  stdout: NodeJS.WritableStream;
  display: Display;
  signal?: AbortSignal;
  resume?: string;
  forceNew?: boolean;
}

export async function runRepl(options: ReplOptions): Promise<number>;
```

**流程**:
1. 加载 `.env`
2. `initSession({ cwd, env, resume, forceNew })` → 默认续接最近 24h session
3. 构造 `AgentHarness`(同 single-shot)
4. 订阅事件 → display
5. `readline.createInterface({ input: stdin, output: stdout, prompt: "mimi> " })`
6. 循环:
   - `await rl.question("mimi> ")`
   - 空行 → continue
   - `exit` / `quit` / EOF → break
   - 其它 → `await harness.prompt(line)`
7. `rl.close()` + harness/storage close
8. 返回 0

**非 TTY 处理**:
- `!stdin.isTTY && !resume && !forceNew` → 自动转 single-shot 模式(用 stdin 第一行作为 prompt)
- 或显式报错退出(由 spec 决定,本 Task 默认前者)

**信号处理**:
- `process.on("SIGINT")` → `harness.abort()` + `rl.close()` + 返回 130

**测试用例**:
- ✅ 输入 "hello" → harness 收到 "hello"
- ✅ 输入 "exit" → 退出,返回 0
- ✅ EOF(流结束)→ 退出,返回 0
- ✅ 空行 → 不调 harness
- ✅ SIGINT → harness.abort 被调,返回 130
- ✅ 非 TTY stdin → 自动转 single-shot(若只有一行输入)

**example**(`02-repl.sh`):
```bash
#!/usr/bin/env bash
set -e
cd "$(dirname "$0")/.."
echo "你好,请用一句话自我介绍" | npx tsx src/cli.ts
```

**验证**:

```bash
bash examples/02-repl.sh
# 预期: 看到模型响应,退出码 0
```

```bash
#!/usr/bin/env bash
set -e

mkdir -p /tmp/mimi-test-sessions

  npx tsx src/cli.ts --new "我的名字叫小明,请记住")

# 第二轮:续接 session,问"我叫什么?"
MIMI_SESSION_DIR=/tmp/mimi-test-sessions \
  npx tsx src/cli.ts --resume "$SESSION_ID" "我叫什么名字?"
```
